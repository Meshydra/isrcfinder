    Questions

    Good to know

    What is an ISRC?

    An ISRC (International Standard Recording Code) is a 12-character code that identifies one specific recording of a song. A remix, a live version and a remaster of the same song each have their own ISRC.

    Is MusicFinder free?

    Yes. The app is free and shows a few ads. If you would rather not see them, one payment removes them forever.

    Why is it not on Google Play?

    MusicFinder is shared directly from this site as an APK file. Android asks you to allow the install the first time; the download page shows the steps.

    Can I look up a song from an ISRC?

    Yes. Paste an ISRC into the search box and MusicFinder shows the recording it belongs to.

    Does MusicFinder play or download music?

    No. It only finds the code and details of a recording. It does not play, download or unlock music anywhere.

    Which phones does it work on?

    Android 8.0 and newer. It needs an internet connection to search.
