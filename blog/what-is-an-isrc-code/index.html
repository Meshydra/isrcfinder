What is an ISRC code? A plain guide

16 November 2026 · 2 min read

Every commercially released recording carries a short code that tells it apart from every other recording in the world. It is called an ISRC, and once you know it exists it solves a lot of "which version is this?" problems.

ISRC in one sentence

An ISRC (International Standard Recording Code) is a 12-character code that identifies one specific sound recording or music video. It is an international standard, ISO 3901.

What the 12 characters mean

Take USUG11904206. Printed in full it is written with dashes: US-UG1-19-04206.

USA two-letter prefix. It was originally the country of the registrant, and today it is simply part of the prefix issued to them.
UG1The registrant: the label, distributor or artist who was issued the block of codes.
19The year the code was assigned, not always the year the song was recorded.
04206A five-digit number the registrant picks for this recording.

The dashes are only for reading. Systems store and search the code without them.

One recording, one code

The code belongs to the recording, not the song. That is the part people miss. One song can have many ISRCs:

  • the album version
  • the radio edit
  • a live performance
  • a remix
  • a remaster
  • a cover by another artist

Each of these is a different recording, so each gets its own ISRC. The same recording appearing on several albums keeps the same code.

What an ISRC is used for

Streaming services, radio monitoring and royalty societies use the ISRC to count plays and pay the right people. For everyone else it is a precise way to point at a recording. Some music searches accept an ISRC directly, which is handy when a title search keeps returning the wrong version. Our guide on finding the exact song on Instagram with an ISRC is one example.

ISRC, ISWC and UPC are not the same thing

ISRCOne recording.
ISWCThe composition: the words and melody, however many times it is recorded.
UPC / EANA product: the single, EP or album as it is sold.

Who assigns ISRCs

Labels and distributors assign them when a track is released. An independent artist usually gets one automatically from their distributor. National ISRC agencies issue registrant prefixes to those who want to assign their own.
